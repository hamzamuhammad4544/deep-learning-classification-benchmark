UCI Classification Datasets (>=20 attributes)
All five datasets below are the original files from the UCI Machine
Learning Repository (https://archive.ics.uci.edu/), retrieved via
long-standing mirrors of the official UCI data files (verified against
each dataset's official UCI page: instance count, attribute count, and
class labels all match).

Format note: All CSV files have NO header row, no whitespace between
columns, and the class label is the LAST column in every file. Missing
values (horse-colic.csv only) are marked with '?'.

Files:
  1. ionosphere.csv    - 351 instances,  34 attributes, 2 classes (g/b)
  2. sonar.csv         - 208 instances,  60 attributes, 2 classes (R/M)
  3. german.csv        - 1000 instances, 20 attributes, 2 classes (1/2)
  4. spambase.csv      - 4601 instances, 57 attributes, 2 classes (0/1)
  5. horse-colic.csv   - 300 instances,  27 attributes, 2 classes (1/2)

Official UCI dataset pages:
  Ionosphere:            https://archive.ics.uci.edu/dataset/52/ionosphere
  Sonar (Mines vs Rocks): https://archive.ics.uci.edu/dataset/151/connectionist+bench+sonar+mines+vs+rocks
  Statlog German Credit:  https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data
  Spambase:               https://archive.ics.uci.edu/dataset/94/spambase
  Horse Colic:            https://archive.ics.uci.edu/dataset/47/horse+colic
